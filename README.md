## About My Github Project

**Work Management Tool for Collaboration and Planning**

Please note there are 3 views that can be clicked: backlog view, priority board view, and roadmap view.

The epics and their features are listed below.

**Epic 1: Task Management** 
* Task creation and organization
* Task collaboration

**Epic 2: Projects and Backlog Structure**
* Create/manage projects
* Hierarchical structure of work – projects, epics, features, sprints, task relationships
* Import/export data

**Epic 3: User Accounts and Permissions**
* Sign-up / login / reset
* SSO integration
* MFA
* Role-based access control (Admin, Team Member, Custom role)
* Profile management

**Epic 4: System Health and Monitoring**
* Error logging and tracking
* Performance monitoring dashboard
* Alerts for errors and performance issues
* Recovery mechanisms
* Audit logging

**Epic 5: Sprint and Performance Tracking**
* Basic sprint metrics (burndown, burnup, velocity) with filters
* User-level performance (tasks assigned, completed, blocked)

**Epic 6: Notifications and Alerts**
* Different badges to indicate different activity: task assignment, comments, mentions notifications
* Separate notifications panel with filtering by type

This project showcases a realistic Version 1 work management system that reflects how teams plan, organize, and track work. Users can create and manage tasks, structure and prioritize backlogs, collaborate with team members, and monitor progress across projects and sprints.

Beyond the system itself, this project demonstrates the product thinking behind it. It shows how the backlog was planned and organized, how features and epics were defined, and how work was prioritized and structured into sprints. It reflects the approach a product manager takes to design a tool that supports team productivity, creates clarity, and enables effective decision-making.
